# MakerWorld listing

## Title

UniFi Cloud Gateway Ultra 10-inch rack mount with four keystones

Published at: https://makerworld.com/en/models/3237102-1u-ucg-ultra-max-10-inch-rack-mount-4x-keystones

## Description

A compact 1U mount for fitting a Ubiquiti Cloud Gateway Ultra and four keystone
jacks into a standard 10-inch rack. The open cradle provides ventilation and
access while retaining the gateway securely.

## Files

- `ucg-ultra-4-keystone.stl` — complete printable rack mount.

## Printing

Print in the supplied orientation. PETG is recommended for a durable rack
installation; PLA is also suitable for moderate indoor temperatures.
