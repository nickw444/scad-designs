# MakerWorld listing

## Title

10-port ⅔U keystone patch panel for a 10-inch rack

Published at: https://makerworld.com/en/models/3237051-10-port-2-3u-keystone-patch-panel-for-10-inch-rack

## Description

A space-efficient 10-inch rack patch panel holding ten numbered keystone jacks
in only two-thirds of a rack unit. It pairs neatly with the 1⅓U NBN NTD mount.

## Files

- `10-port-two-thirds-u-panel.stl` — main patch panel.
- `10-port-two-thirds-u-labels.stl` — aligned port numbers for a separate colour.
- `10-port-two-thirds-u-panel-and-labels.3mf` — combined multi-part project.

## Printing

Print the supplied 3MF, or import both STLs at their original coordinates for
a multi-colour print. PETG is recommended for a durable rack installation.
