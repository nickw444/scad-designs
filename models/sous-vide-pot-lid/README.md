# Parametric sous-vide pot lid

[View this model on MakerWorld](https://makerworld.com/en/models/3072514-sous-vide-pot-lid-cover-for-240mm-pot).

A circular pot cover with a downward locating lip and a U-shaped opening for a sous-vide circulator. Pot diameter, lip dimensions, lid thickness, cutout size, edge offset, and circle resolution are exposed through the OpenSCAD Customizer.

The default model fits a 241 mm outside pot diameter and renders to the local `build/sous-vide-pot-lid.stl`.
