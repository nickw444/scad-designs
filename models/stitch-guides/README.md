# Stitch guides

Four 5 mm-thick rectangular sewing guides with their imperial and metric dimensions debossed into the top face. Each printable entry point is backed by the colocated `stitch-guides.scad` geometry.

| Entry point | Size |
| --- | --- |
| `bow.scad` | 3½ × 7 in / 88.90 × 177.80 mm |
| `tails.scad` | 3½ × 5 in / 88.90 × 127.00 mm |
| `knot.scad` | 1¾ × 2½ in / 44.45 × 63.50 mm |
| `rectangle-3.5x3.scad` | 3½ × 3 in / 88.90 × 76.20 mm |
